# ADR-0002: Single Filament panel for all roles

- Status: Accepted (D-16)
- Context: Employees use the app as well as admins.
- Decision: One panel; visibility via Policies and permissions. Custom pages: My Day, Leave Calendar, My Leave.
- Consequences: One navigation to maintain; every resource and action must be permission-gated (NFR-03). Role-specific panels may be revisited only by ADR.
