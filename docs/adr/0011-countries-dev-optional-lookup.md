# ADR-0011: countries.dev as an optional outbound lookup

- Status: Accepted (owner request, 2026-11-20; recorded as D-61)
- Context: the client wants the "New country" form to look a country up by name on https://countries.dev and fill its code, phone prefix, currency, language and timezone. Until now the application made no outbound call during a request apart from the breached-password check in production. The service is third party, unauthenticated and rate limited (about 60 requests a second per IP), its documentation is inconsistent about the `flag` value and the 404 body, and it only knows timezones as UTC offsets.
- Decision: add `CountryDirectory` (`app/Domain/MasterData/Support`), a small server-side client. Only the typed country name or a two-letter code is sent, never data about people. The base URL, timeout (5 s) and cache lifetime (24 h) are in `config/task-logger.php`. The response is untrusted: names are trimmed, the prefix must be digits, the currency must pass `Money::isIsoCurrency()`, the language must be two lower-case letters, and the flag must be a short non-ASCII string. A 404, a timeout, a 5xx or malformed JSON is logged and gives an empty answer, so the form never breaks and the country can always be filled by hand. The code that comes back from the browser is accepted only as two capital letters. The lookup pre-fills editable fields on create; the existing validation and the `countries.create` permission are unchanged. The timezone comes from `DateTimeZone::listIdentifiers(PER_COUNTRY)` when it yields exactly one zone.
- Consequences: the application works with the service down. Results are cached, so repeated searches do not hit the API. Tests fake HTTP (`Http::preventStrayRequests()` is already on). Countries gain a nullable `language` column. Kosovo (XK) has no PHP timezone mapping, so its timezone is chosen by hand.
- Rejected: calling the API from the browser (exposes the browser to a third party and skips the server checks); bundling a static country list (stale, and the client asked for the API); refreshing existing countries from the API (not asked for).
